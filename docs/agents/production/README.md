# production/

The apparatus the fullstack loop uses on this repo: `test-rig.md` (the rig PLAN
writes last — the instruments, the gate set, the correctness-versus-speed
ordering, written against `rasputin` and the sglang ROCm venv), `lessons-learned.md`
(cross-run memory: escapes, standing rules, the outcome ledger), and
`run-artifacts/` (dispatch briefs under `briefs/`, receipts, and the reports that
GATE comments point at; `run-artifacts/` is created when the first receipt
lands). Nothing here is authored by hand at priming time — PLAN fills it, and a
coder or reviewer only reads what the brief points it at.
